# Timed

![Timed](timed/thumbnail.webp)

A Noctalia plugin for countdown timers started from the bar or launcher,
written in Rust with [noctalia-rs](https://github.com/lumi673/noctalia-rs).

See [timed/README.md](timed/README.md) for usage and duration formats.

## Install

```sh
noctalia msg plugins source add timed git https://github.com/DontBlameMeDev/timed.git
noctalia msg plugins enable dontblameme/timed
```

The plugin directory ships a static x86_64 Linux helper. On another
architecture, build it yourself, refresh `timed/`, and add the repository as a
path source. A path source scans `<dir>/<plugin>/plugin.toml`, so point it at
the parent of `timed/`, not at `timed/` itself:

```sh
cargo build --release --target x86_64-unknown-linux-musl
./target/x86_64-unknown-linux-musl/release/timed emit timed timed-helper
cp target/x86_64-unknown-linux-musl/release/timed timed/timed-helper
noctalia msg plugins source add timed path "$PWD"
```

Then enable `dontblameme/timed`.

### Nix

```sh
nix build
noctalia msg plugins source add timed path "$(readlink -f result)"
```

The flake builds the helper and emits the plugin into `result/timed/`, so the
result directory is a source root. It also provides the development shell and checks:

```sh
nix develop
nix flake check
```

## Layout

| Path | What it is |
| --- | --- |
| `noctalia.toml` | Plugin manifest source: metadata, settings, entries |
| `src/` | The handlers: `service`, `widget`, `panel`, `launcher`, plus duration, timer state, and colors |
| `timed/` | The plugin Noctalia loads, generated by `emit` and committed |
| `assets/` | Plugin README and images |

`timed/plugin.toml` is generated. Change `noctalia.toml` or `src/`, then
regenerate:

```sh
cargo run --release -- emit timed timed-helper
```

## Development

```sh
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --release
python3 .github/scripts/check-catalog.py
cargo deny check
cargo bench --bench perf -- --case launcher_list
```

`timed/` must match a fresh `emit`, which CI checks with `diff`. The formatting,
lint, and dependency rules come from `~/projects/project_templates/rust`:
`.rustfmt.toml`, `.clippy.toml`, and `.deny.toml`. Format with stable rustfmt.
The nightly-only keys in `.rustfmt.toml` are ignored, so stable and nightly
produce the same file except for import grouping.

## Release

Cut a release from a green `main` with one dispatch:

```sh
gh workflow run release.yml -f bump=patch
```

Or rehearse it without pushing, tagging, or publishing:

```sh
gh workflow run release.yml -f bump=patch -f dry_run=true
```

The workflow bumps `Cargo.toml` and `catalog.toml`, runs formatting, clippy,
tests, the catalog check, and the `emit` diff, builds the static musl helper,
regenerates `timed/`, commits the bump and the helper, tags `v<version>`, and
publishes a GitHub release with the helper attached. It needs the
`RELEASE_DEPLOY_KEY` secret, a write deploy key that bypasses the ruleset on
`main`.

To rehearse locally, do the same steps in a scratch copy:

```sh
python3 .github/scripts/bump-version.py patch
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --release
CARGO_TARGET_X86_64_UNKNOWN_LINUX_MUSL_LINKER=rust-lld \
  CARGO_TARGET_X86_64_UNKNOWN_LINUX_MUSL_RUSTFLAGS="-C link-self-contained=yes" \
  cargo build --release --target x86_64-unknown-linux-musl
./target/x86_64-unknown-linux-musl/release/timed emit timed timed-helper
cp target/x86_64-unknown-linux-musl/release/timed timed/timed-helper
python3 .github/scripts/check-catalog.py
```

`nix develop` includes the musl target, so the static build needs no extra
toolchain. Noctalia picks the release up from the git source on its next
update, or with `noctalia msg plugins update timed`.

See [docs/noctalia-plugins.md](docs/noctalia-plugins.md) for the Noctalia plugin
API documentation links.
